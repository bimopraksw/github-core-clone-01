A standalone GitHub-compatible git forge in one Node.js process: git clone/push over smart HTTP (protocol v0 and v2, packfiles with deltas), the REST v3 API (repositories, issues, pull requests, contents), a GraphQL v4 subset in the shapes gh sends, and six MCP tools — all over one in-memory store, standard library only, no git binary, no outside service.

## Run it

```sh
node --experimental-strip-types main.ts
```
